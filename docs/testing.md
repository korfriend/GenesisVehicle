# Testing

| abbr | meaning |
|---|---|
| AST | Abstract Syntax Tree (Python's `ast` module — used as a source-level tripwire) |
| L2 | per-entity batching axis (K vehicles in one scene) |
| L3 | `n_envs` batching axis (same-URDF fleet) |
| M | swept-envelope contact samples per wheel (`contact_samples`) |
| SFL | `StaticFrictionLock` — the hold-at-rest stability hook |
| RR | rolling resistance (`RollingResistance`) |
| cr | rolling-resistance coefficient (`rolling_resistance_cr`) |
| `T_resist` / `T_rr` | axle resisting torque a pre-tire hook sets / its capped value |
| M_eff | effective coast mass, `M + sum(i_wheel / r^2)` |
| ω | wheel spin rate |
| SDF | Signed Distance Field — the per-geom grid genesis builds for non-convex contact |
| dt | one simulation STEP duration (s) |
| H | requested state-send rate (the server's `--send-hz` value, Hz) |
| P | send period, `1/H` (s) |
| substeps | solver iterations per step; internal interval is `dt / substeps` |
| D / Y / Z | v1.8.0 held-wheel deadbeat / lateral deadbeat / their rigid-body scale `s` (`physics-contracts.md` §7.16) |
| ULP | unit in the last place (one float32 step) |
| MPC / NMPC / LMPC | Model Predictive Control / its nonlinear (do_mpc + IPOPT) and linear (OSQP) implementations in `PathFollower` (v2.0.0) |
| PD | the 1.x `PathFollower` law (`mpc_model="off"`) |
| U1 | the `ValueError` a default (MPC) `PathFollower` raises without `mpc_params` |
| R-ALIGN / R-STALL / R-FAIL | v2.0.1 `PathFollower` regimes: PD while the heading gate holds / PD after the watchdog fired / PD after a failed solve |
| s_hw | the furthest path-projection arc length over the earlier R-STALL entries of a block |
| C-vNNN Lk | straight 20 m, a vertex with heading change NNN°, a k m second leg (0.5 m spacing, 4 m/s) |
| SHA-256 | the hash the legacy bit-identity fixture stores per vehicle over 300 steps |
| k_b | v2.0.2 brake gain: modelled deceleration per unit brake (m/s² per unit brake) |
| v_h | a sweep table's grid speed nearest 0, excluding 0 (the gear-mode coast model's hold speed) |
